# 实施计划

本次完成文档基线；下列代码里程碑均尚未实现。

## M1：桌面宿主

搭建 workspace、Electron 主进程、preload、React 界面及 Windows 构建。实现主题、导航、标签和设置。

验收：Windows 启动与关闭正常；renderer 无直接 Node 能力；可生成并安装 EXE；不同缩放无关键控件遮挡。

## M2：数据与插件闭环

实现宿主存储、manifest 校验、安装/启停/卸载和 SDK；以笔记插件验证端到端，再通过待办插件验证复用性。

验收：安装新插件无需重编译宿主；重启后数据保留；越权访问被拒绝；插件故障可恢复；停用撤销接口；卸载保留数据；升级失败可恢复。

## M3：外部只读接口

进入 M3 前完成 [运行时验收](RUNTIME.md) 的多会话、任务调度、挂起恢复和资源监测原型；涉及 MCP 的验收随 M3 完成。所有性能阈值先测量再定稿。

实现 MCP 桥接、命名管道、客户端配对、逐应用授权和审计。

验收：一个实际 MCP 客户端能列出、搜索和读取授权数据；未授权应用不可见；撤销后立即拒绝；应用关闭有明确错误；无写操作和任意 SQL 通道。

## M4：发布准备

锁定依赖、备份恢复、崩溃恢复、手动更新流程、签名与发布策略。确定许可证及第三方依赖清单。

验收：在干净 Windows 环境验证安装、升级、卸载及数据保留，完成主题/缩放/键盘检查。

## 暂缓

插件商店、多设备同步、多人协作、内置 AI、不可信插件执行、任意原生插件、自动更新和复杂分屏。
