# 数据库插件 1.0.0

独立安装 `database-workbench-1.0.0.wbplugin`，使用主体 0.5.0 起已有的 `native.backend` 通用后台能力，无需升级主体或增加数据库业务 IPC。此权限允许可信插件执行本机代码，并非操作系统沙箱。驱动随插件打包，运行时不下载依赖。

MySQL：连接指定数据库、列出表与视图、每页 100 行浏览、字段结构、单条 SQL 执行（包括写入及 DDL）。SQL 执行前确认，最多显示 500 行；超时 15 秒，多语句关闭，不提供跨请求事务。超时及断线后可能需要重新连接，写入失败时需核实服务器实际状态。

Redis：选择数字数据库、SCAN 模式搜索和继续扫描、字符串 / 哈希 / 列表 / 集合 / 有序集合预览、字符串修改与有效期、删除键。预览最多 100 项，哈希与集合为首个扫描批次，COUNT 是服务器提示值；字符串预览最多 64 KiB。当前不支持集群、Sentinel、SSH 隧道、自签名 CA、二进制无损编辑。SCAN 不构成一致性快照，空批次仍可继续扫描。

连接元数据存储于插件数据目录 `connections-v1.json`，版本 1，写临时文件后原子替换。未知版本或损坏文件拒绝加载并保留原文件；卸载默认保留数据。密码仅用于会话，不写入配置，不记录 SQL、键值、结果或凭据。TLS 验证服务器证书。初始连接列表为空。

驱动源文档：[mysql2](https://sidorares.github.io/node-mysql2/docs)、[node-redis](https://redis.io/docs/latest/develop/clients/nodejs/)。依赖锁定在 pnpm-lock.yaml，构建时由 esbuild 内联到插件后台；主体只承担已有通用运行时职责。

自动验证覆盖输入、分页、标识符转义、配置持久化、损坏版本保护、Redis 游标与写入校验、已安装包驱动加载及资源权限。真实 MySQL / Redis 服务兼容性、Windows 安装升级卸载及数据保留冒烟仍需发布前验收。
