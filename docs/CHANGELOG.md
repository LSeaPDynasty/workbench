## 影音库插件 1.1.0（主体保持 0.5.1）

- 新增完整 SHA-256 内容索引，同内容多位置去重；外部改名、移动、时间属性变化后重新扫描仍保留身份、收藏、资料和歌单。内容改变会创建新身份；缺失记录保留，不清掉歌单关联。
- 新增本地歌单创建/重命名/删除、歌曲增删和排序，浏览器及局域网端只读选择与播放歌单；新增本地显示名、歌手及专辑资料编辑和哈希查看。
- v2 索引与 v1 分开持久化，旧索引原样保留，首次重新扫描迁移可定位的旧收藏及 ID 别名。未首次补齐哈希前已经移动的旧路径无法可靠迁移，见影音库说明。
- 38 项自动测试和实际音视频/歌单界面回归通过。仅发布独立插件包，不修改或重建主体。

## 0.5.1

- 插件管理新增「在线获取」，从现有 GitHub Release 发行通道发现全部可下载插件，包括尚未安装的应用；支持搜索、刷新、大小和版本展示、下载安装及跳转已安装/可更新列表。
- 新安装沿用私有发行通道认证，验证 SHA-256、实际大小、插件 ID、版本、包格式及资源路径。下载后确认全部权限，取消不安装、不启动后台，禁止在线新安装覆盖已有插件；原更新流程保留启停状态和数据。
- 本地包安装入口保留为「从文件安装」，失败后可重试。主体升至 0.5.1，插件版本不变。
- 31 项测试、类型检查和构建通过；浏览器回归覆盖网络失败重试、搜索、取消/失败/成功安装、状态切换、更新和明暗主题。真实 Electron 网络请求读取 6 个已发布插件，成功校验并安装影音库到隔离目录。
- 打包后 app.asar 的真实页面、preload 和 IPC 验证在线目录、下载、取消/确认安装（测试自动回答权限弹窗）、重载后显示及注册表持久化。Windows 已有安装的覆盖升级/卸载仍待实机验收。

## 影音库插件 1.0.0（主体保持 0.5.0）

- 新增独立本机后台插件，选择性扫描本地音乐/视频文件夹，支持分类、搜索、收藏、目录封面和同名 VTT 字幕。扫描可取消，分页读取索引，媒体按流传输。
- 浏览器播放器支持音视频直放、拖动、倍速、当前列表切歌和本机播放进度；手机尺寸页面适配。默认仅本机，手动开启局域网只读共享；关闭插件停止服务。
- 打包脚本自动发现插件目录；插件包自行携带后台与播放器，不修改主体代码、不重新生成 EXE。
- 不包含转码、刮削、DLNA 或 Jellyfin API；浏览器不支持的编码无法直放。真实手机跨设备 Wi-Fi 与 Windows 防火墙验收仍待完成。

## 0.5.0 / Git 插件 2.0.0

- 将 GitService、Git 命令工作线程、GitHub 认证与请求模块迁出主体，全部作为 Git 插件后台资源发布；移除主体所有 Git 业务 IPC 和 Git preload API。
- 新增通用 backend 声明、独立 utility process、插件自带 SDK、进程懒启动/停止/重启以及专属数据目录。
- 新增 native.backend 完整本机代码信任权限，明确不是 OS 安全沙箱；安装升级需确认权限。Git 旧数据由插件自己迁移，旧文件保留。
- 23 项自动测试和浏览器回归通过；真实 Electron utility process 测试验证无 Git 时零后台、无关插件独立升级与数据保留、Git 包内后台迁移账号及读取真实 GitHub 数据。真实原生窗口安装升级验收仍待完成。

## 0.4.0 / Git 插件 1.1.0

- 新增已登录 GitHub 账号的远端仓库列表，包含拥有、协作和组织成员身份可访问的仓库，按最近推送排序，每页 30 个。支持搜索已加载内容、可见性筛选、分页、浏览器打开和选择目标父文件夹克隆。
- 仓库列表与克隆按选中账号读取 GitHub CLI 凭据，不依赖全局当前账号；凭据仅在后台子进程环境使用，不返回页面或写入远端地址。
- Git 界面默认展示远端仓库，侧边栏单独列本地仓库；编辑账号使用独立按钮，手动添加本地仓库改为弹窗。修复新初始化仓库因无提交而不能显示状态，纠正差异统计路径参数。
- 仓库查询与分页逻辑放在插件 `github.js`，宿主只提供绑定账号的受限 GET、浏览器打开和原生 Git 克隆，避免每增加一个业务界面都升级主体。
- 19 项自动测试、类型检查和构建通过；真实账号查询返回 27 个可访问仓库，真实私有仓库克隆成功。浏览器模拟 SDK 验证列表、筛选、分页、克隆后打开本地、弹窗、导航和浅深色布局。真实 Electron 窗口及升级验收仍待完成。

## 0.3.3 / Git 插件 1.0.2

- 浏览器登录改为后台会话，实时显示设备授权码和状态；宿主显式打开固定 GitHub 授权页，不依赖隐藏 CLI 的终端交互。
- 等待登录不再全局禁用按钮；支持取消登录、手动打开授权页、失败/超时重试。关闭插件或退出主体会终止未完成的登录进程。
- 使用标准 GitHub CLI 安装路径，并将 Electron 解析到的系统 HTTP 代理传给登录进程。
- 新插件需要主体 0.3.3 的登录 SDK；旧主体会显示升级提示。主体和 Git 插件均需更新。
- 16 项自动测试通过；浏览器模拟 SDK 检查状态、授权码、非阻塞导航、取消、重试及完成。真实 GitHub CLI 已取得设备码，验证后取消；未替用户进行新的账号授权，真实 Electron 窗口验收仍待完成。
