# 栖桌：工作书桌与工作舞台

2026-11-06 第二版视觉实验。栖桌为暂定展示名。本规范取代第一版固定侧栏、标签栏及蓝白后台风格。

## 外壳

顶部保留品牌、当前位置、应用搜索、主题切换和设置。Windows 保留原生窗口框架。底部应用托盘提供书桌、笔记、待办、文件及添加工具入口，图标始终带文字；打开过的应用有小标记，当前应用有明确选中状态。

右下角工作页面按钮展开会话列表，支持切换与关闭。当前仅实现应用级会话，未实现同应用多文档、拖拽排序及真正挂起。

首页展示当前笔记内容、未完成待办和其他笔记，移除统计卡片。进入应用后使用完整内容区域。不同插件可选择编辑器、表格、画布等布局，不要求全部使用同一模板。

## 风格

暖灰背景、纸白内容、石墨文字、低饱和青绿强调，值来自 design/tokens.css。纸面边缘和少量阴影表达层次，装饰只用于首页。深色使用深绿灰；实际无障碍审计仍待进行。

主标题约 28–32px，页面标题约 25px；托盘紧凑，内容区留白。小窗口托盘保持可见，内容区域纵向滚动。

## 行为与验证

支持托盘、搜索和会话列表切换应用；停用后阻止入口访问。首页可添加待办、继续编辑和新建笔记。Ctrl+K 聚焦搜索，图标按钮均带可访问名称。

已进行浏览器自动检查：应用切换、会话关闭、笔记保存及重载、待办、示例入口启停、深浅主题、960px 无水平溢出。已检查浅深主题及小窗口截图。

当前数据为 localStorage；插件安装、SQLite、后台执行、MCP 均未接入。EXE 运行限制见 PREVIEW-VALIDATION.md，本轮不宣称已修复。基础组件范围沿用 UI-LIBRARY.md。
