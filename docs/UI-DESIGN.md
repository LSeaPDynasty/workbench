# UI 风格：安静、清晰的桌面工作台

实现选型见 [UI 库选型与自建边界](UI-LIBRARY.md)：shadcn/ui + Radix 基础组件，自建 Workbench UI 业务组件。当前是规范，尚未完成组件实现和视觉验证。

## 视觉方向

浅色为默认主题，深色可切换并可跟随系统。中性灰背景、白色内容表面、蓝色主操作。采用紧凑但不拥挤的桌面密度；不用大面积渐变、玻璃模糊和装饰性卡片。

字体：Segoe UI Variable、Segoe UI、Microsoft YaHei UI、sans-serif。正文 14px，辅助文字 12px，页面标题 20px。图标统一线性风格，常规 18px，图标配合文字或可访问名称。

## 布局

- 顶部保留 Windows 原生窗口框架，第一版不做自绘标题栏。
- 应用内工具栏 44px：全局搜索、任务状态及设置。
- 左侧应用栏默认 208px，可折叠至 56px，底部固定插件管理和设置。
- 内容区顶部标签栏 36px；页面标题与操作按钮同一行。
- 内容区域按 24px 外边距、16px 分组间距布局；表格和列表优先于重复卡片。
- 建议最小窗口 960×640 DIP；较窄时折叠侧栏，保持关键操作可见。

## 颜色与组件

实际颜色、间距和圆角以 design/tokens.css 为准。主按钮实心蓝，次按钮描边，危险操作红色。一般容器圆角 8px，输入框与按钮 6px；普通内容容器使用边框，阴影只用于浮层。

按钮默认高 32px，输入框 34px，列表行 36px。禁用态不能仅靠颜色表达；选中项同时使用背景及标记。焦点环始终可见。正文对比度目标 WCAG AA，落地后实际测量，不声称当前已通过测试。

## 交互约定

- Ctrl+K 打开全局搜索；Ctrl+, 打开设置；Esc 关闭最上层浮层。
- 标签关闭操作保留未保存提醒；不自动丢弃内容。
- 空态给出原因及一个明确操作，例如“还没有笔记 → 新建笔记”。
- 加载显示骨架或进度；长任务可取消，失败提供重试和简短原因。
- 插件安装页展示名称、版本、来源、权限及兼容状态。
- AI 访问位于“设置 → 外部访问”，展示授权应用、配对客户端、最近调用及撤销入口。
- 默认不显示聊天框、模型选择器或 AI 品牌元素。

## 插件界面一致性

SDK 提供主题 token 和主题变化事件；宿主负责导航、标签、确认对话框和通知。插件页面只绘制自身业务内容，避免重复侧栏和重复设置框架。

## 验收

检查浅色/深色、100%/125%/150% 缩放、键盘导航、中文长标题、空/加载/错误/无权限状态。多面板拖拽作为后续增强，确认实际需求后再引入 Dockview。
