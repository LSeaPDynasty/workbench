# 影音库 1.1.0

## 安装与使用

需要主体 0.5.0 的通用本机后台运行时。主体 0.5.1 可在「插件 → 在线获取」安装，已安装用户在插件管理检查更新即可；也可安装 `local-media-1.1.0.wbplugin`。本次仅更新插件，无需更新主体。

1. 添加媒体库，选择音乐、视频或全部，再选择需要加载的文件夹。后台扫描不会复制或修改媒体。
2. 使用分类、搜索或收藏筛选；点击媒体在浏览器播放。添加、停用、移除媒体库及扫描操作只在桌面插件内提供。移除媒体库不删除原文件。
3. 点击「局域网共享」，选择端口并手动开启，将播放链接交给同一可信局域网内的设备。关闭共享立即断开共享流并使旧链接失效。

共享不会随启动自动打开。切换到其他应用仍可继续共享；关闭、停用或卸载影音库，或退出工作台，会停止所有播放器服务。不是常驻系统服务。

## 播放与索引

### 歌单、资料与文件身份

- 侧栏新建歌单，媒体卡片的「⋯」可编辑显示名、歌手、专辑、查看 SHA-256 及加入歌单。歌单支持重命名、删除、上移、下移和移出歌曲，重复加入不会重复记条；仅接受音乐。局域网客户端可选择和播放歌单，不可修改。
- 自建本地索引 `catalog-v2.json` 以完整文件字节的 SHA-256（64 位十六进制）作为唯一 ID，独立保存内容记录、全部已扫描位置、自定义资料、收藏及有序歌单。文件名、目录、修改时间等不参与 ID；在文件管理器中改名、移动后重新扫描即可重新关联，插件内的显示资料编辑只写索引，不改媒体文件。
- 同内容的副本跨媒体库合并展示。播放时优先使用已启用目录中的可读副本，首个位置失效会尝试其他副本；目录授权和启停状态仍生效。不同内容即使路径、大小相同，也视为新文件，不继承原文件歌单和收藏。
- 完整扫描找不到的内容保留索引记录、资料及关联，在桌面歌单中标记「文件不可用」。恢复到任一已选择媒体库后重新扫描可恢复。移除媒体库和删除歌单都不删除原文件。共享端隐藏无可用位置的歌曲。
- 每次扫描都逐文件、以 1 MiB 缓冲完整重算哈希，不仅凭大小/时间复用旧哈希；大文件首轮及复扫需要读取全部字节。扫描前后校验文件状态，中途修改则不接纳该次结果。取消不提交未完成的扫描；有错误或达到上限的目录保留未遍历的旧位置，避免误清关联。播放前状态变化会提示重新扫描，不在每次 Range 请求中重读全文件做哈希。
- 修改媒体内嵌 ID3、封面等文件字节会改变哈希，应视为另一条内容。外置封面、字幕不计入媒体文件哈希。当前不直接重命名磁盘文件、不写入内嵌标签，也不自动监听文件系统变化。
- 索引最多保留 5 万条内容记录（含不可用记录）及 5 万个位置，200 个歌单，每单最多 1 万首；达到上限不自动删除旧关联。索引存储上限 64 MiB。

### 从 1.0.0 升级

旧 `catalog-v1.json` 原样保留。升级后点击「重新扫描」补齐哈希，将旧路径 ID 和收藏映射到内容 ID；旧 ID 作为兼容别名。媒体仍在旧路径时才能可靠建立初次映射，所以建议先完成这次扫描，再批量改名或移动。旧版从未保存内容哈希，无法推断已经消失的旧路径属于哪段内容。

浏览器遇到兼容别名时将该浏览器已有收藏和续播位置迁至新 ID。浏览器数据受同源存储约束，服务端口/访问地址不同不会自动同步。迁移后不覆盖旧索引，损坏的 v2 索引会明确报错，不自动清空；退出应用后可以保留 v2 备份并回退旧包与旧索引。

- 扫描音乐 MP3、FLAC、WAV、M4A、AAC、OGG、OPUS；视频 MP4、M4V、WebM、MKV、MOV、AVI。容器被识别不代表浏览器支持其中编码。当前直接传输原文件，不转码、不转封装；不支持的格式需要自行转换后播放。
- 音乐歌手/专辑从目录推断，标题来自文件名；尚不解析内嵌 ID3 等标签。目录中的 `cover/folder/poster.jpg/jpeg/png/webp` 用作封面。同目录、同名 `.vtt` 文件用作字幕。
- 支持原生播放控件、拖动、倍速和当前已加载列表的前后曲；音乐结束自动播放列表下一曲。浏览器可能阻止自动播放，点击原生播放按钮即可。
- 桌面收藏保存在插件索引；浏览器收藏和续播位置保存在各浏览器本地，彼此不同步。不包含刮削、DLNA、Jellyfin API、电视客户端和用户账号系统。
- 每页 60 项，单次索引最多 5 万媒体、遍历 25 万目录项、深度 32 层，跳过符号链接与目录联接。达到上限会提示截断；增删媒体后手动重新扫描。
- 后台按需启动，扫描异步执行；文件按流读取，最多 12 个活动文件流及 32 个连接。封面、字幕有大小上限；桌面封面超过 256 KiB 不预览，播放器封面上限 4 MiB。不新增依赖。

## 局域网边界

默认播放器仅监听回环地址。显式共享后监听 IPv4 接口，仅接受本机/私网来源及已知 Host，使用随机链接密钥交换 HttpOnly、SameSite Cookie；密钥从地址栏片段移除。会话有效期 12 小时，停止/重启服务使会话和链接失效。拿到链接的人可以读取已启用媒体库，不要把链接公开。

HTTP 用于可信局域网，没有 TLS 加密；不自动开放防火墙、不配置路由器、不支持公网发布。端口默认 8098，可更换。连接失败时检查设备同网段、端口冲突、网络隔离和 Windows 专用网络防火墙规则，不必关闭整个防火墙。

`native.backend` 代表信任插件执行本机 Node.js 代码，不是系统沙箱。网页接口只读，通过不含路径的媒体 ID 访问；每次读文件复核所选目录授权。停用媒体库会拒绝新访问并断开其正在传输的流。

## 验证范围

已完成自动化索引/持久化、目录边界、HTTP 鉴权与 Range/HEAD、字幕封面、链接轮换、停止释放端口、独立包安装和后台重启测试；浏览器回归实际播放 WAV 和 WebM，检查收藏、倍速、暂停、明暗主题及手机尺寸页面。

全项目 38 项测试通过，覆盖哈希改名/移动/属性变化、重复文件多位置、相同路径不同内容、歌单顺序与持久化、缺失恢复、旧索引迁移、取消与扫描中修改、共享只读和停用后数据过滤。浏览器使用真实 WAV 与已验证的 WebM 测试片检查播放，并操作歌单、排序、资料、改名、重复副本和不可用状态。后台及 HTTP 为真实实现，测试页面桥接与权限弹窗由测试驱动。

手机尺寸回归使用本机浏览器访问共享监听器；真实手机跨设备 Wi-Fi、防火墙以及不同设备编码兼容性仍需实机验收。

使用已发布的 0.5.1 app.asar 中原有 Registry、BackendManager 和 utility runner，实际验证 1.0.0 → 1.1.0 升级、v1 收藏/别名迁移、原索引保留、改名、歌单资料及后台进程重启后的持久化。未修改或重建主体。
